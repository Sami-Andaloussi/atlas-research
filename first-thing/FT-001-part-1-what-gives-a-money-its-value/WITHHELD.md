# Withheld

What this folder leaves out of the study's files, and why. The values a licence keeps from republication are cited, never republished: each dataset's manifest says where to fetch them.

## Datasets published as their manifest only

Built by us, but not republished: they hold values from sources whose licence does not allow it, or transcribe a printed work's table (each row names its page). Each manifest says what it holds and where its sources are:

- `data/reconstructed/ft001-a/`
- `data/reconstructed/ft001-a3/`
- `data/reconstructed/ft001-b/`
- `data/reconstructed/ft001-cs-tables/`

## Files withheld

| File | Why |
|---|---|
| `results/runs/C23-cs-c-losses-by-era.json` | CS-C's events name frame b's rows (Reinhart and Rogoff's and JST's values behind them) and IRR's classes; regenerated by code/p1_cs_c.py |
| `results/runs/C25-k9-crises-by-debt.json` | K9's count on JST R6 (CC BY-NC-SA 4.0), computed from JST's values, which are not republished in bulk; the counts printed in the methods are ours; withheld as C23's is, as a precaution; regenerated by code/p1_k9_debt.py |
| `results/runs/C24-cs-c-years-in-crisis.json` | CS-C's years in crisis, counted on frame b's readings (the BIS's and Reinhart and Rogoff's values behind them); regenerated by code/p1_cs_c_years.py |
